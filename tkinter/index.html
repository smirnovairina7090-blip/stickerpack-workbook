01

Что такое Tkinter?

Обычно Python общается с нами через консоль. Tkinter позволяет сделать интерфейс, в котором можно нажимать кнопки, вводить текст и открывать окна.

▣

Определение

Tkinter - стандартный модуль Python для создания графического интерфейса (GUI) с окнами, кнопками, полями ввода и другими элементами.

▤

Аналогия

Представь конструктор. Окно - основа, виджеты - детали, а функции объясняют деталям, что делать при нажатии.

✦

Где используют?

Калькуляторы, небольшие программы, формы регистрации, таймеры, заметки, викторины и учебные проекты.

Запомни! GUI (Graphical User Interface) - графический интерфейс пользователя. Именно он позволяет управлять программой через видимые элементы, а не вводить команды в консоль.

Одна команда сообщает Python, какие готовые возможности мы хотим использовать. Проверь три способа импорта и попробуй написать команду сам.

После такого импорта классы пишутся с полным именем: tkinter.Tk().

03

Первое окно за 6 строк

Сначала подключаем модуль, затем создаём главное окно, настраиваем его и запускаем цикл обработки событий.

Рабочий код

hello.py
import tkinter as tk

root = tk.Tk()
root.title("Моё первое окно")
root.geometry("400x300")

root.mainloop()
mainloop() - как дежурный на стойке информации: он ждёт нажатий, движения мыши и других событий, чтобы приложение реагировало на них.

Разберём по шагам

1

import tkinter as tk - подключаем библиотеку и сокращаем имя до tk.

2

root = tk.Tk() - создаём главное окно. root - его переменная.

3

root.title(...) - задаём текст в заголовке окна.

4

root.geometry("400x300") - размер: ширина 400 и высота 300 пикселей. Буква x латинская.

5

Позже добавим кнопки, надписи и поля ввода.

6

root.mainloop() - запускаем цикл событий. Обычно эту строку ставят последней.

Что случится, если забыть mainloop()?

В обычном скрипте программа не будет нормально ожидать событий: окно может мгновенно закрыться или не успеть отобразиться. В некоторых интерактивных средах ситуация отличается.

06

Как расставлять элементы

Есть три основных менеджера геометрии. Попробуй переключить режим и сравнить расположение элементов.

Кнопка AКнопка BКнопка C

pack() располагает виджеты друг за другом, как вещи в стопке.

Примеры расположения

Python
tk.Button(root, text="A").pack(pady=8)
tk.Button(root, text="B").pack(pady=8)
tk.Button(root, text="C").pack(pady=8)
Важно: не смешивай pack() и grid() внутри одного и того же контейнера. В разных Frame можно использовать разные способы.
07

События и полезные методы

Приложения становятся интересными, когда реагируют на действия человека. Для этого нужны функции, события и методы настройки.

Кнопка запускает функцию

Обработчик события
def say_hello():
    print("Привет!")

button = tk.Button(
    root,
    text="Поздороваться",
    command=say_hello
)
button.pack()

command=say_hello передаёт функцию кнопке. Если написать say_hello(), функция вызовется сразу при создании кнопки.

Когда нужен bind()?

Клавиатура
def on_enter(event):
    print("Нажали Enter!")

root.bind("<Return>", on_enter)

bind() связывает событие с функцией. Например, <Return> - клавиша Enter, а <Button-1> - левый щелчок мыши. Функция-обработчик принимает аргумент event.

Основные методы, которые стоит знать

Быстро найди нужную команду, когда будешь писать собственный проект.
