# Карточка товара - интерактивная проектная мастерская

Интерактивный рабочий лист для урока по созданию рекламной карточки товара в Canva и с помощью генеративных инструментов.

## Что внутри

- мини-бриф продукта;
- тренажёр визуальной иерархии;
- живой макет с палитрой и проверкой контраста;
- пошаговый маршрут сборки в Canva;
- конструктор промта для Canva Magic Media и 24AI;
- контроль качества и самооценка проекта;
- автоматическое сохранение ответов в браузере.

Лист не требует регистрации, не запрашивает имя ученика и не содержит функции печати.

## Источники и сервисы

- [Canva](https://www.canva.com/)
- [24AI](https://app.24ai.tech/ru/ai-studio)
- [remove.bg](https://www.remove.bg/)
- [Adobe Color](https://color.adobe.com/create/color-wheel)

Фирменный стиль: «Креайтивика», шрифт Manrope, палитра и правила бренда заказчика.
